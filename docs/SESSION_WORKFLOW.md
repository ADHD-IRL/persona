# Session workflow

## Recommended path

1. Choose **Start session** under Run. Scenario and decision pages lead to this same guided start, carrying the selected context.
2. Frame the question, review the SME panel, and run the analysis in the background. A comparison creates one debate per option.
3. Use the contextual progress card in **Session Tracker** to monitor active work, stop/resume, and view saved debate responses. Open **Run details** for the full run record.
4. Choose **Continue in Session Tracker** for the desired debate. Review findings, manage follow-up, inspect evidence, compare earlier debates, prioritize decision impact, and record closeout there.

Session Tracker remains the home page. Contextual cards show preparing, running, or failed work when attention is needed. Completed runs leave room for findings and the session brief. **Session history** is a browser for saved sessions, reached from the tracker; every session opens its tracker.

## Screen responsibilities

| Screen | Purpose |
| --- | --- |
| Start session | Prepare and launch guided work |
| Run details and brief | Monitor, stop/resume, and read the analysis-wide brief |
| Session Tracker | Manage one debate's findings, evidence, follow-up and conclusion |
| Debate transcript | Read saved responses from a guided run; no independent run controls |
| Session history | Find an older session and open its tracker |
| Scenarios / Decisions | Develop reusable inputs, then launch through Start session |

Suggested follow-up on an analysis can be saved once. Edit its status, completion evidence and criteria in Session Tracker. Analysis-wide suggestions currently attach to the first debate; the saved-action link opens that specific session.

## Advanced paths

Expand **Advanced: manual or live facilitation** on Start session for manual/facilitated setup or a live panel. Manual setup creates a draft and opens its tracker; **Continue manual debate**, **Continue facilitated debate**, or **Continue live panel** opens the correct room. Browser-driven rounds require the room to stay open. The tracker remains the management home after synthesis.

Manual debate, live panel and results screens provide **Return to Session Tracker** for that session. Existing URLs remain supported. Guided sessions opened through old manual/live/panel URLs show the read-only transcript, preventing a competing execution path beside the background worker.

Session history hides edit/reset/delete behind **Show advanced maintenance for manual sessions**, available to administrators. Guided runs use their saved-input resume/reassessment workflow instead of resetting individual debate records.

## Changes made after workflow review

- Replaced competing sidebar entry points with one Start session entry.
- Moved session history behind the tracker and advanced creation choices under the guided start.
- Removed the scenario-page restriction that required an edit before another run; guided readiness and reuse govern reassessment.
- Moved follow-up editing from analysis results into the tracker.
- Made running jobs visible from the management home even before they create a session.
- Replaced generic Back links with session-specific return links and routed continue buttons by execution mode.
- Preserved advanced specialist tools and old links while separating guided transcript viewing from manual execution.
