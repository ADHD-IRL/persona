# Session Summary

Open Manage > Session Summary to reference a completed debate on one page. The selector labels sessions by scenario, question or name, and date. It defaults to the last selected completed session when available, otherwise the most recent completed debate. A direct link uses /session-summary?session=SESSION_ID. Session Tracker also links to the summary after completion.

The page shows the scenario and question, saved analyst conclusion and disposition, selected debate synthesis, findings and threats, chains, response actions and completion criteria, sources, open questions, accepted risks, and revisit conditions. Section links jump within the same page. Editing stays in Session Tracker and the related threat or chain library.

Guided analysis uses its saved scenario snapshot; manual sessions without a snapshot show the current scenario with an explicit label. Findings and actions are scoped to the selected session and its directly linked records. Parent-analysis findings are labeled separately and are not counted as selected-session findings. A completed debate does not imply completed analyst review. Unconfirmed closeout drafts do not replace the last saved review. Model output and source quotations remain unverified unless separately assessed.

Refresh summary reloads the session index and displayed materials. There is no background polling. Missing, unfinished, and empty-session states provide explicit guidance rather than showing another session's material.
