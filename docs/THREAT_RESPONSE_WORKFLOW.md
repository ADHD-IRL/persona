# Threat review and response planning

Start in Needs attention to find unreviewed findings, missing evidence, overdue responses, or changed context. Select a finding and use Understand, Review evidence, and Plan a response. Ordinary links open references and the originating Session Tracker. Advanced editing and duplicate merging stay collapsed; Bulk manage exposes selection controls.

Response actions are the same saved mitigation records used by Session Tracker. Choose Verify a claim, Reduce the risk, or Monitor for change. Existing records remain Unclassified until an analyst assigns a purpose. Record observable completion criteria, a due date if needed, and evidence of completion. Implemented and verified actions prompt reassessment of previously reviewed findings; they do not automatically lower risk.

AI decision and response assistance uses the selected finding, its evidence, scenario context, existing actions, and your decision goal. It compares options or proposes responses with rationale, tradeoffs, uncertainties, and completion criteria. No external research is performed. Generate suggestions, then Review as response action to populate an editable draft. Save response action explicitly creates a proposed linked record. Repeated saves of the same title on the same finding and step reuse the existing record. Model and generation time are included in editable draft notes. Advice does not write a final Decision record or approve actions.

Cancel generation stops the request. Invalid or incomplete output is not offered for saving. Changed record context requires fresh advice. Read-only access cannot create or edit responses. No live model calls are required by the automated test suite.
